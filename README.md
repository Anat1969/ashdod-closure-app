# מנהל סגירות — עיריית אשדוד (גרסה עצמאית)

גרסה עצמאית של האפליקציה, ללא תלות ב-Base44.

**כתובת האפליקציה:** https://ashdod-closure-app.vercel.app

## איך זה עובד
- האתר מתארח בחינם ב-GitHub Pages ומתעדכן אוטומטית בכל שינוי בענף `main`.
- **הנתונים (בקשות, קבצים ותמונות) נשמרים בדפדפן של כל משתמש** (IndexedDB), ואין שרת.
  - בקשה שנשמרת במחשב אחד לא מופיעה במחשב אחר.
  - כדי להעביר נתונים או לגבות אותם, משתמשים בכפתור **"גיבוי נתונים"** בראש המסך (ייצוא / ייבוא של קובץ JSON).
  - ניקוי נתוני האתר בדפדפן מוחק את הנתונים, לכן כדאי לייצא גיבוי באופן קבוע.

## הבדלים מגרסת Base44
| יכולת | Base44 | גרסה עצמאית |
|---|---|---|
| התחברות משתמשים | חשבון Base44 | אין צורך בהתחברות |
| שמירת נתונים | שרת משותף | דפדפן מקומי + גיבוי לקובץ |
| ייבוא בקשות ממסמך | AI (PDF/Word/תמונה) | Excel / CSV עם העמודות: שם העסק, כתובת, סוג העסק, סוג הסגירה |
| שליחת מייל | נשלח מהשרת | פותח את תוכנת הדואר שלך עם ההודעה מוכנה |

## חדש בגרסה זו
- **מסמך מדיניות מצוטט:** כל סעיף עם מספר, חיפוש מילות מפתח עם הדגשה ומעבר בין תוצאות, העתקת ציטוט מלא וקישור ישיר לסעיף.
- **משחק המדיניות:** "בונים סגירה" (חתך רחוב חי שמשתנה עם כל פרמטר, ציון התאמה ואתגר תיקון) ו"נכון או לא נכון", כל תשובה עם סעיף.
- **מפת סגירות:** שכבת בקשות לפי סטטוס וסוג, שכבת עסקי מזון באשדוד מ-OpenStreetMap, רחובות מובילים, ופתיחת תיק ישירות מהמפה.
- **הגדרות:** גיבוי, מפת בסיס (אפורה, רחובות, תצלום אוויר), שכבת OSM, נתוני הדגמה, מחיקה.
- התקנה כאפליקציה מ-Chrome.

## יכולות עיקריות
- **בעל עסק:** טופס הגשה בשלבים, שמירת טיוטה והמשך מילוי מאוחר יותר, בדיקת תקינות של דוא"ל ותאריכים, איתור מיקום לפי כתובת, העלאת תמונות, תוכניות ו-PDF, תפריט עסק.
- **עירייה:** רשימת בקשות עם סינון, חיפוש ומיון, דף בקשה מפורט עם מפה, אישור / החזרה לתיקון / דחייה, היסטוריה, הדפסת דוח בדיקה (או שמירה כ-PDF), העתקת הדוח, פתיחת מייל מוכן, מחיקת בקשה, ייצוא לאקסל, וייבוא רשימת עסקים מאקסל (עם תבנית להורדה).
- **מפה:** סימון צבעוני לפי סטטוס, סינון, סימון ותיקון מיקום (בלחיצה על המפה או לפי כתובת). בקשות שלא סומן להן מיקום מוצגות בשקיפות.
- **תושב:** מפת העסקים המאושרים עם תמונה ותפריט.
- מספרי בקשה עוקבים לפי שנה (ASH-2026-001, ...).
